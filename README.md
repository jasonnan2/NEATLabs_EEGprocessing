# NEATLabs EEG Processing

A unified workspace for EEG data processing and analysis, integrating EEGLAB with automated analysis tools and custom pipelines.

---

## Getting Started

### Prerequisites
* MATLAB (R2020b or newer recommended)
* Git

---

## Installation

To download the entire workspace along with all submodules in one command:

```bash
git clone --recurse-submodules [https://github.com/jasonnan2/NEATLabs_EEGprocessing.git](https://github.com/jasonnan2/NEATLabs_EEGprocessing.git)
```
